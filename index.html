    Five rules that answer most exam questions
    
  
    
    
    Indexes start at 0
    First character s[0], last s[s.Length - 1]. The slide's myString[1] prints the second character.
    
    
    Strings never change
    Every method returns a new string. Write s = s.ToUpper(); to keep the result.
    
    
    Length is a property
    No brackets: s.Length. Spaces count as characters.
    
    
    -1 means not found
    IndexOf and LastIndexOf return -1, never 0, when there is no match.
    
    
    Second number is a length
    Substring(start, length) and Remove(start, count), not start and end.
